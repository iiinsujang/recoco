# 1.0 (99) 소스 정리

2026년 11월 24일 공개한 iPhone 앱을 기준으로, 11월 26일 GitHub의 오래된 앱 소스를 정리했습니다.

## 포함

- 앱 구현, 리소스와 31개 언어, Xcode 프로젝트와 고정된 패키지 버전
- 앱·화면 테스트, 출시 설정과 번역 점검 도구
- 로컬 구성 예제, 기존 공개 개인정보·약관·지원 문서
- 빌드와 검증 범위를 설명하는 문서

## 제외

- Firebase 구성 파일, 비공개 키, 실제 환경 변수, 인증서와 서명 프로파일
- 기기 백업, 개인 사진, QA 상세 로그, 아카이브·설치 파일과 임시 산출물
- 호스팅된 웹 시험판·투표 서비스의 운영 데이터와 배포 환경

핵심 11개 파일은 [출시 시점 해시 목록](1.0-99-core-manifest.json)과 일치합니다. 나머지 앱 소스·리소스와 테스트도 현재 출시 작업 폴더에서 복사했으며, 동기화를 위해 앱 동작을 변경하지 않았습니다. 이번 정리에서 새로 작성한 내용은 공개용 문서와 제외 규칙입니다.

출시 프로젝트가 참조하는 비공개 로컬 설정은 별도로 준비해야 합니다. 공개 소스만으로 실서비스 Apple 로그인과 인증 해제를 재현할 수 있다고 보장하지 않습니다.
